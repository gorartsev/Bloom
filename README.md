# BLOOM

Тренировочный лог и слой ИИ-тренера под конкретное расписание: БЖЖ три раза в неделю, бег три раза, короткая силовая прицепом к мату, калистеника и мобильность дома.

Приложение пишет данные. Тренер их читает и возвращает план. Всё локально, без аккаунтов и без сети.

## Приложение

PWA, ванильный JS, ноль зависимостей, ноль CDN. Работает офлайн по-настоящему, через service worker, а не на честном слове браузерного кэша.

**Что умеет**

- Силовая с полным логом подходов: вес, повторы, RIR. Подход пишется одним тапом, значения подставляются из прошлого раза.
- Подсказка по прогрессии на каждом упражнении: двойная прогрессия с гейтом по RIR.
- Таймер отдыха, стартует сам после подхода, звук и вибрация в конце.
- Быстрый лог для мата, бега и мобильности: длительность, RPE, заметка. Пятнадцать секунд.
- Недельная нагрузка по методу Фостера (минуты × RPE) и ACWR как индикатор перегруза.
- Каталог на 83 упражнения с подсказками по технике, из них 41 помечено как прямо работающее на БЖЖ.
- Календарь, запись задним числом, рекорды, вес, график.
- Импорт плана от тренера и экспорт данных для него.
- Две темы, тёмная и розовая.

**Файлы**

| Файл | Что |
|---|---|
| `index.html` | Разметка и все стили |
| `data.js` | Каталог упражнений, типы сессий, шкалы |
| `app.js` | Состояние, рендер, расчёты |
| `sw.js` | Офлайн. Поднимать `VERSION` при каждом деплое |

## Слой тренера

| Файл | Что |
|---|---|
| `CLAUDE.md` | Точка входа: что читать под какую задачу, форматы плана и экспорта |
| `coach/PROFILE.md` | Данные, расписание, цели, ограничения |
| `coach/PROGRAM.md` | Текущий блок: структура недели, схемы, целевая нагрузка |
| `coach/PROGRESSION.md` | Правила прогрессии, красные флаги, порядок урезания |
| `coach/REVIEW.md` | Как разбирать сессию |
| `coach/FLAGS.md` | Память между сессиями. Читается первой при планировании |

## Цикл

```
план от тренера  →  вставил в приложение  →  тренировка  →  экспорт  →  разбор  →  флаги  →  следующий план
```

1. Тренер отдаёт JSON. Профиль → «Вставить план от тренера».
2. План появляется на главной, кнопка разворачивает его в сессию.
3. После тренировки: Профиль → «Скопировать данные для тренера», вставить в чат.

## Разработка

```bash
python3 -m http.server 8899     # открыть http://localhost:8899
node --check app.js data.js sw.js
```

Правки в `app.js`, `data.js`, `index.html` требуют поднять `VERSION` в `sw.js`, иначе телефон будет держать старую версию.

`overflow-x:hidden` на `html/body` ставить нельзя: ломает `position:sticky` у шапки и таймера отдыха.

## Деплой на GitHub Pages

Settings → Pages → Deploy from a branch → `main`, папка `/(root)`.
Дальше открыть ссылку в Safari, Поделиться → «На экран Домой».

## Данные

`localStorage["bloom"]`, схема `v:2`. Старый розовый дневник (`v:1`) мигрирует автоматически при первом запуске: тренировки, вес и настроение переезжают в новую схему.
Резервная копия: Профиль → «Скачать резервную копию».
